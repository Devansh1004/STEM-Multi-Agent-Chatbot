# Euler-Mascheroni Constant

Name: Euler-Mascheroni constant

Symbol: γ

Approximate value: 0.5772156649015329

Definition:
The Euler-Mascheroni constant is defined as the limiting difference between the harmonic series and the natural logarithm.

Definition:
γ = lim(n→∞) [1 + 1/2 + 1/3 + ... + 1/n - ln(n)]

Properties:
- Its irrationality is currently unknown.
- It appears in number theory and analysis.
- It is related to the harmonic series.
- It occurs in several formulas involving the gamma function and logarithms.

Common uses:
- Number theory
- Mathematical analysis
- Harmonic series
- Gamma function
