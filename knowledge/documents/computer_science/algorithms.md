# Algorithms

Name: Algorithms

Definition:
A finite sequence of well-defined instructions to solve a problem or perform a computation.

Categories:
- Sorting algorithms: quicksort, mergesort, bubble sort.
- Searching algorithms: binary search, linear search.
- Graph algorithms: breadth-first search, depth-first search, Dijkstra's algorithm.

Properties:
- Binary search runs in O(log n) on sorted data.
- Quicksort has average time complexity O(n log n).

Common uses:
- Software development
- Competitive programming
