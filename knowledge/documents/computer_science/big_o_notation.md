# Big O Notation

Name: Big O Notation

Definition:
A mathematical notation describing the upper bound of an algorithm's running time or space requirement as input size grows.

Common classes:
- O(1) constant time
- O(log n) logarithmic time
- O(n) linear time
- O(n log n) linearithmic time
- O(n^2) quadratic time
- O(2^n) exponential time

Properties:
- Faster growing complexities perform worse for large input sizes.
- Used to compare algorithm efficiency independent of hardware.

Common uses:
- Algorithm analysis
- Technical interviews
