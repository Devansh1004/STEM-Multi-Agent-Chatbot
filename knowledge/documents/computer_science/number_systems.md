# Number Systems

Name: Number Systems

Definition:
Methods of representing numbers using a fixed base and set of digits.

Common bases:
- Binary (base 2): digits 0 and 1.
- Decimal (base 10): digits 0 through 9.
- Hexadecimal (base 16): digits 0 through 9 and A through F.

Properties:
- Conversion between bases is done by repeated division or positional weighting.
- Computers store data in binary.

Common uses:
- Computer architecture
- Digital electronics
