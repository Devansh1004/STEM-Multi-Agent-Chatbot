# Data Structures

Name: Data Structures

Definition:
Ways of organizing and storing data for efficient access and modification.

Types:
- Arrays: fixed-size contiguous memory, O(1) indexed access.
- Linked lists: nodes with pointers, O(1) insertion at head.
- Hash tables: key-value storage, average O(1) lookup.
- Trees: hierarchical structure, O(log n) search in balanced trees.

Common uses:
- Software engineering
- Database indexing
